# Gradient Descent Algorithm

It is an algorithm that is used to **minimise the cost function**  $J(w,b)$.

Here,
- We start with some initial values for $w$ and $b$.
- We then repeatedly update $w$ and $b$ to reduce the cost function $J(w,b)$.
- We continue this process until we reach or get close to a minimum of $J(w,b)$.

Gradient descent essentially asks:
"Which direction should I move \(w\) and \(b\) so that the cost decreases?"

---
### Update Rules

The update rules are:

$$
w := w - \alpha \frac{\partial}{\partial w}J(w,b)
$$

$$
b := b - \alpha \frac{\partial}{\partial b}J(w,b)
$$

where:

- $w$ → weight/parameter
- $b$ → bias/parameter
- $J(w,b)$ → cost function
- $\alpha$ → **learning rate** 
- $\frac{\partial}{\partial w}J(w,b)$ → derivative of the cost function with respect to $w$
- $\frac{\partial}{\partial b}J(w,b)$ → derivative of the cost function with respect to $b$

- **Repeat until Convergenc** -The update process is repeated until the algorithm converges (ie., till both w and b have reached values where further updates produce very little change in the cost.)

---
## Simultaneous Update

The updates to $w$ and $b$ must be **simultaneous**.

This means that both new values are calculated using the **old values** of $w$ and $b$.

We use temporary variables:

$$
tmp\_w =
w-\alpha\frac{\partial}{\partial w}J(w,b)
$$

$$
tmp\_b =
b-\alpha\frac{\partial}{\partial b}J(w,b)
$$

Then update both parameters:

$$
w = tmp\_w
$$

$$
b = tmp\_b
$$
---

### Learning Rate $\alpha$

The **learning rate $\alpha$** controls how large a step we take during each update.

- Small $\alpha$ → smaller steps → slower convergence
- Large $\alpha$ → larger steps → may overshoot the minimum

The goal is to choose a suitable learning rate so that the algorithm reaches a minimum efficiently.

---
## Derivative Function

The **derivative** tells us the **direction and rate at which the cost function is changing**.

For linear regression:

$$
\frac{\partial}{\partial w}J(w,b) = \frac{1}{m}\sum_{i=1}^{m}\left(f_{w,b}(x^{(i)})-y^{(i)}\right)x^{(i)}
$$

$$
\frac{\partial}{\partial b}J(w,b) = \frac{1}{m}\sum_{i=1}^{m}\left(f_{w,b}(x^{(i)})-y^{(i)}\right)
$$

---

## Batch Gradient Descent

- **Batch Gradient Descent** uses **all training examples** in every gradient descent step.
- If there are $m$ training examples, each update uses all $m$ examples.

The update rules are:

$$
w := w - \alpha \frac{1}{m}
\sum_{i=1}^{m}
\left(f_{w,b}(x^{(i)})-y^{(i)}\right)x^{(i)}
$$

$$
b := b - \alpha \frac{1}{m}
\sum_{i=1}^{m}
\left(f_{w,b}(x^{(i)})-y^{(i)}\right)
$$

### Example

If:

$$
m = 47
$$

then **all 47 training examples** are used to calculate each update of $w$ and $b$.

> **Batch = use the entire training dataset for every update.**
