# Cost Function

## Linear Regression Model - Function

**f<sub>w,b</sub>(x) = wx + b**  
- Here, w (weight - slope) and b (bias - y-intercept) are the parameters.
- Different values of w and b will give us different results.
- For example,

1. f(x) = 0x + 1.5, where w = 0, b = 1.5

```text
        intercept b = 1.5
```

---
### Prediction

For a training example $i$, we have:

$$
(x^{(i)}, y^{(i)})
$$

where:

- $x^{(i)}$ → input of the $i^{th}$ training example
- $y^{(i)}$ → actual target/output

The model makes a prediction:

$$
\hat{y}^{(i)} = f_{w,b}(x^{(i)})
$$
---

### Prediction Error

The difference between the predicted value and the actual value is the **error**.

$$
\text{error} = \hat{y}^{(i)} - y^{(i)}
$$

---
### Squared Error Cost Function

The cost function used here is called the **squared error cost function**.

Inorder to calucate the average error we use, 
$$
\frac{1}{m}
\sum_{i=1}^{m}
\left(\hat{y}^{(i)} - y^{(i)}\right)^2
$$

The \(m\) [number of training sets] gives the average over the training examples, while the \(1/2\) is included for mathematical convenience when computing derivatives during optimization.

$$
J(w,b) =
\frac{1}{2m}
\sum_{i=1}^{m}
\left(\hat{y}^{(i)} - y^{(i)}\right)^2
$$
