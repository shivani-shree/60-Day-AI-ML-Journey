# Regression
It is the type of Supervised Learning used to predict a number or continuous numerical value.
Example: House price prediction
```text
House Size (x) -> House Price (y)
```

## Linear Regression
- Linear Regression is a regression algorithm that fits a straight line to the training data to predict the target value.
- It finds a straight-line relationship between x(input) and y(output).

```text
Price
  ↑
  |
  |                         ●
  |                    ●
  |                ●
  |            ●
  |       ●
  |   ●
  |____________________________→
                Size
```
### Notations used
|Notation | Meaning|
|---|---|
|x | Input feature|
|y | Output/Target|
|m | Number of training examples|
|(x,y) | Single training example|
|x⁽ⁱ⁾ | Input x of the i-th training example|
|y⁽ⁱ⁾ | Target y of the i-th training example|

---
Here,

```text
Training set (features + targets)
              ↓
      Learning Algorithm
              ↓
         Function (f)

x → f(x) = wx + b → ŷ
```
---

A linear regression model with one feature is represented as:  
**f<sub>w,b</sub>(x) = wx + b**

```text
            f(x) = wx + b

w (weight) → slope
b (bias) → intercept
```
---

### Prediction ŷ
ŷ = **f<sub>w,b</sub>(x)**

ŷ represents the predicted value produced by the model, while y is the actual target value from the training data.

---

### One Variable
This means that our model has one input feature
Example: x -> house size and y -> house price
so, its 1 feature → 1 target

This is also called Univariate linear regression.
