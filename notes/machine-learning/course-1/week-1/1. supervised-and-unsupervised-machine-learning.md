# What is Machine Learning?

- Machine Learning is the field of computer science where algorithms learn patterns from data and use those patterns to make predictions or decisions.
- It gives computers the ability to learn without being explicitly programmed.

```text
Data -> Learning Algorithm -> Model  
New Data -> Model -> Prediction
```
---
# Types of Machine Learning

1. Supervised Learning
2. Unsupervised Learning
3. Reinforcement Learning
---

## Supervised Learning

X (input) -> Y (output)

- The model learns from labeled data, where the desired output is known.

Key idea:
```text
Supervised learning: "Learn from examples with known answers."
```

### Types of Supervised Learning
1. Regression: Predicts continuous numerical value (Eg., predicting the price of the house from the previous input and output)
2. Classification: Predicts category/class (Eg., Tumor -> Benign / Malignant)

---

## Unsupervised Learning
- The algorithm works with data where the desired output or target labels are not provided (unlabeled data).

Key idea:
```text
Unsupervised learning: "Find useful patterns in unlabeled data."
```

### Type of Unsupervised Learning
1. Clustering: Grouping similar data points together (Eg., Customer segmentation)
2. Anomaly Detection: Identifies unusual examples that differ significantly from normal patterns (Eg., Fraud Detection)
