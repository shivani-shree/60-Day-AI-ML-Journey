## 🎯 Focus

## 📚 Learned
- Linear regression fits a straight line through data so we can predict a number (like a price) from an input.
- The cost function measures how wrong the line is by averaging the squared gaps between predictions and real values; lower cost means a better fit.
- A Git branch is a separate line of work, so I can try changes without touching `main`.
- `git merge` brings a branch's changes into another branch.
- A merge conflict happens when two branches change the same lines; I fix it by choosing what to keep, then committing.
