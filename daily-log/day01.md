## 📚 Learned
- Machine learning means a program learns patterns from data instead of being told exact rules.
- Supervised learning uses labeled data (input + correct answer); unsupervised learning finds patterns with no labels.
- `git init` starts a new repo; `add` stages changes, `commit` saves them, `log` shows history.
- `.gitignore` tells Git which files to never track (like secrets or virtual environments).
